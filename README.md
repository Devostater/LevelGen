# LevelGen

Procedural Level Generator for Unreal Engine 5.8, by Quantum Drop Studios.

This repository holds the public documentation. The plugin itself is sold on Fab.

- [User guide](docs/USER_GUIDE.md)
- [Support and common questions](docs/SUPPORT.md)
- Sample narrative tables: [Mind Space](themes/mindspace-narrative.json), [The Hill Relay](themes/relay-narrative.json)
- [Demo project](demo/LevelGenHost): three demo maps for UE 5.8. Add the plugin from your Fab download to its `Plugins` folder. See the user guide.
